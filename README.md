# Proteus

Proteus is an experimental game engine with the emphasis on _developer choice_. But what does _developer choice_ really mean? It means just that, you as the _developer_ of your game get choice in how you use this engine. All of the info for that will be in future documentation.

Right now, Proteus is _highly_ unstable and only has plans to export games for Windows, Linux and macOS. Consoles, mobile devices, and the web are not targets yet.

## Open source, forever!

Proteus is free, open source software. It's licensed under the highly popular, highly permissive [MIT license](./LICENSE). No special clauses, no monetary incentive. Your games are your own, and you're welcome to fork this project and modify it to better suit your needs! Development is active, every commit can be seen and audited. 

## Getting Proteus

### Pre-built tools

You can download a pre-built, stable suite of tools in the [releases](./releases) page of this repository.

### Pre-built library

If you're _code-first_ you can download a pre-built static library of Proteus, including docs and headers from the [releases](./releases) page of the repository.

### Build from source

Proteus is a CMake project and thus heavily relies on it for building. Check out the [building from source](.) documentation to build Proteus from source.
